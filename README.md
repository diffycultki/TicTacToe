# TicTacToe
Руководство по использованию игры «Крестики‑нолики»
Игровое поле представляет собой сетку 3×3, включающую 9 ячеек. Перед стартом требуется определить, какой знак («Х» или «О») будет использовать каждый игрок.

Традиционно первый ход делает участник, выбравший «Х». Ходы совершаются поочерёдно; после размещения знака в ячейке его нельзя переместить или заменить.

Задача игрока — выстроить три своих символа в ряд: по вертикали, горизонтали или диагонали.
